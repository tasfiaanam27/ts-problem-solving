# TypeScript Problem Solving Assignment

This repository contains solutions to 10 TypeScript problem-solving challenges.

## Problems Solved

1. **Merge Two Sorted Arrays** 
   Merges two sorted arrays using the two-pointer technique.
2. **Shopping Cart Total Calculator**
   Calculates the total cost after applying item discounts and tax.
3. **Validate an Email Address**
   Validates email addresses using regular expressions.
4. **Greatest Common Divisor**
   Finds the GCD of two numbers using the Euclidean algorithm.
5. **Longest Increasing Streak**
   Finds the longest contiguous strictly increasing sequence in an array.
6. **Split Array into Chunks**
   Divides an array into smaller chunks of a specified size.
7. **Validate Bangladeshi Mobile Number**
   Checks Bangladeshi mobile numbers against valid formats using regex.
8. **Calculate Days Between Dates**
   Calculates the difference between two dates, including leap years.
9. **Convert Object to URL Query String**
    Converts object properties into a URL-encoded query string.
10. **Sum the Main and Secondary Diagonals**
    Calculates the sums of both diagonals of a square matrix.

## Concepts Practiced

- TypeScript Functions and Type Annotations

- Array Methods (`reduce`, `map`, `slice`, `join`)
